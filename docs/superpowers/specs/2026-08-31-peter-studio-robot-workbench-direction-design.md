# Peter Studio Robot Workbench Direction Design

## 目标

将项目升级为一个统一的个人机器人工作室叙事：`peterstudio.online` 是 Peter Studio 的物理 AI 工作台与 Build Log；机械臂负责证明桌面 AI 助手能力；六足机器人负责建立角色感、探索感和自媒体传播性；`bimanual.org` 继续作为独立的具身智能资讯与 SEO 网站。

本设计不锁定具体的机械臂生活任务，也不要求立即购买或完整开发六足机器人。它只确定长期分工、内容语言和执行优先级。

## 已确认的方向

### 1. Peter Studio 的新定位

Peter Studio 不再以旅行、城市和泛个人思考作为首页主线，而是以“一个人从自己的工作台出发，逐步打造真实机器人伙伴的个人实验室”为核心。

“彼得·帕克的工作台”只作为创作灵感和叙事参照，最终视觉必须发展为原创的个人工作室语言，不直接复制影视作品中的商标、角色造型、徽标、道具、音乐、台词或界面。

### 2. 两个机器人分工

| 机器人 | 主线职责 | 首要价值 | 暂不承担的责任 |
|---|---|---|---|
| 机械臂 | Assistant Capability Track | 验证 Camera、Voice、LLM/VLM/VLA 与现实操作，完成桌面 AI 助手任务 | 不预设具体 Flagship Task |
| 六足机器人 | Character & Reach Track | 建立角色、移动性、探索感、互动感和视频传播性 | 不在第一阶段承担复杂桌面助手功能 |

两条线共享可能的基础设施：Camera、Microphone、Speaker、Screen、LLM/VLM、控制与日志系统、实验数据、内容生产流程和安全规范。共享基础设施不等于两个机器人必须同步开发。

### 3. 机械臂任务仍然开放

机械臂具体要完成哪些真实生活任务，继续通过 `Desktop AI Assistant Task Research`、开源案例研究、平台内容研究和早期实验决定。桌面整理、递取物品、内容创作辅助、桌面办公辅助、人机互动、AI + 机械臂，以及后续发现的新方向，都只能作为候选，不得在项目文档中写成最终 Flagship Task。

## 内容与视觉系统

Peter Studio 的视觉和内容可以借鉴“漫画中的个人发明家工作台”感，但必须服务于真实制造过程，而不是只做装饰。

核心视觉元素：

- 临时拼装感；
- 桌面实验室；
- 手写笔记、零件、工具和失败记录；
- 机器人草稿、测试痕迹和版本变化；
- 漫画式分镜；
- 状态标签、警告、测试结果和动作反馈；
- 一个普通人边学习边造机器人的真实感。

自媒体内容可以使用漫画式分镜重新包装实验过程，例如将一次任务拆成“问题出现 → 尝试方案 → 机器人反应 → 失败 → 修改 → 新结果”。漫画形式是表达层，不得替代真实实验记录；最终内容仍应保留实际视频、命令、数据、失败原因和边界说明。

## 网站职责

### peterstudio.online

定位为个人工作室、物理 AI Build Log 和作品展示站。建议的信息架构方向：

- Workbench：工作台首页和当前状态；
- Robots：机械臂与六足机器人的角色和能力档案；
- Assistant：机械臂桌面助手实验；
- Hexapod：六足机器人角色、运动和互动实验；
- Build Log：按时间记录真实制造过程；
- Experiments：可复现实验、失败和指标；
- Sketchbook：草图、漫画式分镜、设计观察和视觉笔记。

原有旅行与个人文章可以归档保留，但不再作为首页核心叙事。

### bimanual.org

继续保持具身智能相关资讯、技术解释、案例整理和 SEO 内容定位。它不应被改造成 Peter Studio 的个人日志镜像；两者可以互相引用，但必须有清晰分工：Peter Studio 讲“我正在造什么”，bimanual.org 讲“这个领域发生了什么、如何理解和实践”。

## 60 天执行原则

1. 机械臂是第一能力主线，优先完成可验证的控制链路和真实桌面任务实验。
2. 六足机器人可以同步调研和做低成本角色验证，但不与机械臂争夺第一阶段的工程资源。
3. 前 1–2 周继续完成用户场景研究、开源案例研究、内容案例研究和技术可行性验证。
4. 机械臂最终 Flagship Task 仍需经过候选池评分和早期实验后选择。
5. 每次实验优先记录真实证据；内容标题、漫画分镜和视觉包装在实验结果之后生成。
6. 不为“蜘蛛感”购买大量装饰或复制受保护 IP 资产；先用桌面、工具、标签、草图和失败痕迹建立原创识别度。
7. 六足机器人和机械臂未来可以协作，但协作不是 60 天前期的必需交付物。

## 验收标准

- 项目中只有一个明确的长期总方向：打造真实存在于物理世界中的 Physical AI；
- 机械臂被明确写为桌面 AI 助手能力主线；
- 六足机器人被明确写为角色与传播副线；
- Peter Studio 被写为个人机器人工作台与 Build Log 载体；
- 漫画式分镜被写入内容生产规则，但不替代真实证据；
- `bimanual.org` 与 Peter Studio 的职责不混淆；
- 所有具体任务仍然保持候选状态，未提前锁定 Flagship Task；
- 现有 Day 1–7、Developer Experience、Portfolio 和 Guided Execution 结构继续保留。
