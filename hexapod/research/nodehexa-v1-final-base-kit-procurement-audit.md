## 6. 官方 MG90S 核对结论

官方 README 明确：

- 主控是 ESP32（NodeMCU-32S）；
- 推荐 MG90S；
- 市面 MG90S 厂家和尺寸差异较大；
- README 还提供了官方测试筛选的独立 MG90S 商品链接。

但当前套件 SKU 图片只写“舵机×18”，虽然图片中的舵机外观/标签显示为 MG90S 类，仍没有把这 18 个舵机绑定到 README 的独立商品 ID、厂家和具体批次。

```text
OFFICIAL_RECOMMENDED_SERVO = UNKNOWN
KIT_SERVO_COUNT             = 18（已确认）
KIT_SERVO_FAMILY            = MG90S 类（图片证据）
EXACT_SERVO_SOURCE          = 待确认
```

这不会阻止选择官方基础套件，因为套件是官方 README 直接链接的复现入口；但收到货后第一项验收就是核对 18 个舵机的品牌/型号、尺寸、输出轴、安装耳和实际质量。

这里的采购就绪判断针对“核心物料是否已经作为一个可运动套件被明确提供”，不是宣称所有单个器件的厂家参数都已完成工程认证。核心板卡、18 个舵机、打印结构件、充电器、电池和紧固件均已在同一套件 SKU 图片中出现，因此不把“型号细节待确认”误判成“核心物料缺失”。

## 7. 官方套件 vs 自己散买

| 维度 | PLAN_A：官方完整套件 | PLAN_B：按 BOM 自己散买 |
|---|---|---|
| 价格 | 目标 SKU ¥619；价格已确认 | 不能只用舵机/ESP32/PCA9685零散价格估算，完整 3D 打印、定制 PCB、紧固件、电池仍缺价 |
| 舵机一致性 | 同一套件一次提供 18 个，批次一致性相对更好 | 需要自行确认 18 个同型号和机械尺寸 |
| 机械兼容性 | 和套件打印件一起销售，返工风险最低 | 舵机/舵盘/打印件尺寸匹配由自己承担 |
| PCB 风险 | 直接使用官方供电主板 + 两块舵机板 | 需要购买/焊接/确认定制板，不能把两块通用 PCA9685 当作完全等价替代 |
| 采购复杂度 | 一个 SKU + 工具 | 多个店铺、多个型号、多个运输包裹 |
| 返工风险 | 主要是装配和校准 | 还包括物料遗漏、接口、板卡和打印件兼容问题 |
| 时间成本 | 最快进入教程、烧录和运动复现 | 需要重新核对 BOM、打样/打印和装配 |
| V1 推荐 | **推荐** | 仅在已有打印、电子装配和测量能力后考虑 |

因此，不能因为散买理论上可能便宜几十元就选择 PLAN_B。当前目标是先得到一台能按官方教程复现的 NodeHexa，官方整套包更符合这个目标。


这里需要区分两个口径：

- **推荐 SKU + 工具**：`¥619 + ¥50 = ¥669`

因此本报告的推荐预算为 **¥714**；若只计算购买套件和必要装配工具，则为 **¥669**。

### 最高基础版本成本

如果选择带机盖、部分组装、2000mAh 的 E 版本：

¥748 仍未包含任何 AI/传感器设备，但 E 的额外花费主要买的是机盖、部分装配和更大电池，不是基础行走能力。因此不作为当前首选。

## 10. 为什么不推荐其他 SKU

### 不选 A 作为主推荐

A 最便宜，但全部未组装。对第一次复现来说，关节方向、舵盘中位、腿段装配和紧固件位置的错误概率更高。它是经济替代，不是当前最稳妥路线。

### 不选 D/E

机盖对外观和后续“蜘蛛感”内容有价值，但不影响第一阶段运动复现。D/E 的溢价应留给后续完成基础运动后再决定是否购买或打印外观升级。

### 不选 2000mAh

2000mAh 只增加容量，也增加电池质量和价格；本阶段没有续航指标，且首要目标是一周内完成基础行走。先用轻量的 850mAh 版本更容易验证原版运动。

## 12. 购买后验收，不是现在继续搜索

购买后只做基础套件验收：

1. 对照 NodeHexa `mechanism/README.md` 清点六足紧固件。
2. 确认主板、两块舵机板和开发板的具体型号。
3. 确认 18 个舵机是否同型号、是否为 MG90S、重量和外形是否一致。
4. 确认舵盘、连接器、开关、XT30 和线材是否实际随包。
5. 用万用表确认 XT30、VCC、+5V、GND，再连接舵机。
6. 按官方教程完成装配、烧录、校准和基础运动。

这些是到货验收和安全测试，不是继续扩大采购范围，也不改变当前“传感器/AI/执行器升级采购均未就绪”的状态。
