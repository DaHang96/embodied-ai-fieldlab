# Robot Task Selection

> 当前状态：尚未选择最终 Flagship Task；“助手”只是可能的应用方向。

## 选择条件

具体生活任务要在前 1–2 周完成任务调研、候选评分和早期实验后再确定。最终选择 2–4 个任务，不能仅依据传播想象，也不能仅依据技术炫技，而要同时考虑：

- 技术上做得出来；
- 60 天内有较大机会完成；
- 普通观众能快速理解；
- 有明确的真实生活意义；
- 画面有意思；
- 可以反复实验并统计结果；
- 失败也值得记录和传播；
- 可以逐步接入 Camera、Voice、LLM、VLM、Policy、VLA、Screen 或 Speaker；
- 适合当前桌面空间、预算和安全边界。

候选研究和评分见 [task-research.md](task-research.md)。在研究完成前，不在此文件写入已选任务或最终结论。
